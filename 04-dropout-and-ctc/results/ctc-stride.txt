설정: 음성 데이터 없음. 문법으로 만든 전사 400개(seed 21), 발화 속도는 초당 9~18글자 균등(seed 3),
      프레임 하나 = 10ms. 계산량은 순방향 순환 layer 5개, hidden 2048 가정.
      정렬 수는 forward 점화식(정수 산술)으로 세고 T<=9 는 완전탐색과 비교.

== 1. 라벨을 내는 데 필요한 최소 스텝 수 ==

  the cat           7         0          7
  letter            6         1          7
  bottle            6         1          7
  bookkeeper       10         3         13
  aaaa              4         3          7
  mississippi      11         3         14
  bigram 단위로 자르면 인접 중복이 생기는 경우
  aaaa           -> ['aa', 'aa']                 |y|=2 인접 중복 1 최소 스텝 3

  letter         -> ['le', 'tt', 'er']           |y|=3 인접 중복 0 최소 스텝 3
  the cat        -> ['th', 'e ', 'ca', 't']      |y|=4 인접 중복 0 최소 스텝 4

    글자 29개 / 프레임 168 -> 스텝 28. 문자 단위는 29 스텝 필요(부족 1), bigram 단위는 15 스텝 필요 (가능)

    글자 31개 / 프레임 178 -> 스텝 30. 문자 단위는 31 스텝 필요(부족 1), bigram 단위는 16 스텝 필요 (가능)
      "the quiet window opened quietly"

== 4. 출력 단위의 어휘 크기 ==
  문자 단위  : 글자 24종 + blank = 25
  bigram 단위: 말뭉치에 실제로 나타난 겹치지 않는 조각 132종 + blank = 133
               (이론상 최대 24^2 + 24 = 600, 실제로는 132종만 쓰인다)
  출력 길이  : 문자 14,010개 vs bigram 7,099개 (0.507배)
  인접 중복  : 문자 587쌍 vs bigram 0쌍 (blank 를 끼워야 하는 자리)

== 5. 계산량 ==
  가정: 순방향 순환 layer 5개, hidden 2048. 한 스텝당 순환부 MAC = 5 x 2 x 2048^2 = 41.9M
  stride     스텝     순환부(G MAC)        출력층 문자(M MAC)      출력층 bigram(M MAC)       합 비율

       2 53,775         2255.5               2753.3                14647.4     1.0053
       3 35,916         1506.4               1838.9                 9782.9     1.0053
       4 26,987         1131.9               1381.7                 7350.8     1.0053
       8 13,598          570.3                696.2                 3703.9     1.0053
  출력층이 전체에서 차지하는 비율: 문자 0.12%, bigram 0.65%

== 6. bigram 단위가 늘리는 것과 줄이는 것 ==
  stride 2: 표현 가능 발화가 400/400 -> 400/400 로 0개 늘고, 출력층 MAC 은 5.3배가 된다
  stride 4: 표현 가능 발화가 400/400 -> 400/400 로 0개 늘고, 출력층 MAC 은 5.3배가 된다
  stride 8: 표현 가능 발화가 144/400 -> 400/400 로 256개 늘고, 출력층 MAC 은 5.3배가 된다

== 6b. 계산량을 맞춰서 비교하면 ==
  문자 단위 stride 4  : 스텝 26,987, 전체 1133.3 G MAC, 표현 가능 400/400
  bigram 단위 stride 8: 스텝 13,598, 전체 574.0 G MAC, 표현 가능 400/400
  같은 표현 범위를 지키면서 계산량이 1.97배 줄어든다
